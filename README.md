# HR Analytics Dashboard
This project is an HR Analytics Dashboard in MS Excel, aimed at providing key insights into employee data, including demographics, tenure, salary distribution, and leave balance. The dashboard helps HR teams make data-driven decisions regarding workforce management and employee retention.


# Features

Employee Demographics: Breakdown of employees by gender, department, and branch.

Tenure Analysis: Categorization of employees based on tenure and age.

Salary Distribution: Insights into salary variations across departments and employment types.

Leave Balance Overview: Tracking of remaining leave balances for employees.

Interactive Visualizations: Easy-to-use filters for deeper analysis.


# Dataset

The dataset consists of 3,891 employee records with the following key attributes:

ID: Unique employee identifier

Gender: Male/Female

FTE: Employment type (Full-time/Part-time)

Employee Type: Permanent, Contract, etc.

Department: Employee’s department

Branch: Work location

Salary: Employee’s salary

Leave Balance: Remaining leave days

Date of Join: Employee’s joining date

Date of Birth: Employee’s birthdate

Tenure: Employee’s work duration in years

Age: Employee’s age


# Technologies Used

MS Excel for data visualization and dashboard building


# Insights from the Dashboard

Gender Distribution: Identifies the gender ratio within different departments.

Tenure Analysis: Highlights the distribution of new vs. experienced employees.

Salary Trends: Examines salary variations by department and employment type.

Leave Balance Tracking: Provides an overview of employees with low leave balances.

Department-Wise Insights: Helps HR managers assess workforce distribution.


# How to Use

Open the or Excel file for the dataset and dashboard.

Explore interactive filters to analyze specific trends.

Use insights for workforce planning and decision-making.
